How do you turn a cyclic economy into a DAG?

Two answers live in this repository. SCC condensation preserves every inter-component relationship by compressing cycles. MWAS keeps the original nodes and finds an ordering that preserves as much weighted flow as possible.

Approach 01

SCC condensation

Find mutually reachable groups, then collapse each group to one component. The result is always a DAG.

cycles → SCCs → condensation DAG
Approach 02

Maximum-weight acyclic subgraph

Keep the industries separate, choose an ordering, and minimize the weighted feedback that points backward.

weighted digraph → best order → forward DAG + feedback
Tutorial 1 · Strongly connected components

Compress the cycles.

An SCC is a maximal set of nodes in which every node can reach every other node. Condense each SCC to one node and cyclic internal structure disappears, while relationships between components remain.
